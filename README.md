# Их Засаг Политехник Коллеж — Flask + SQLite + Admin Panel

## Боломжууд
- Нүүр, Бидний тухай, Хөтөлбөрүүд, Мэдээ, Холбоо барих
- Хөтөлбөрийн дэлгэрэнгүй ба элсэлтэд шилжих холбоос
- Элсэлтийн бүртгэлийг SQLite-д хадгалах
- Админ нэвтрэх / гарах
- Бүртгүүлэгчдийн жагсаалт
- Нэр, утас, имэйл, мэргэжлээр хайх
- Бүртгэлийг устгах (POST хүсэлт)
- Responsive дизайн

## Windows / VS Code дээр ажиллуулах

1. ZIP файлыг задлаад хавтсыг VS Code-оор нээнэ.
2. `Terminal -> New Terminal` нээнэ.
3. Virtual environment үүсгэнэ:
   ```powershell
   py -m venv venv
   ```
4. Идэвхжүүлнэ:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\venv\Scripts\Activate.ps1
   ```
   Хэрэв аль хэдийн `(venv)` харагдаж байвал дахин идэвхжүүлэх шаардлагагүй.
5. Flask суулгана:
   ```powershell
   python -m pip install -r requirements.txt
   ```
6. Админ хэрэглэгч үүсгэнэ:
   ```powershell
   flask --app app create-admin
   ```
   Хэрэглэгчийн нэр оруулна. Нууц үгийг асуухад терминал дээр тэмдэгт харагдахгүй байх нь хэвийн. Дор хаяж 12 тэмдэгттэй, бусад газарт ашигладаггүй нууц үг сонгоно.
7. Сайтаа ажиллуулна:
   ```powershell
   python app.py
   ```
8. Веб сайт:
   `http://127.0.0.1:5000`
9. Админ панел:
   `http://127.0.0.1:5000/admin/login`

## Өгөгдлийн сан
`database.db` файл анхны ажиллуулахад автоматаар үүснэ. Хуучин төслийн `database.db` байгаа бол түүнийг хадгалж үлдээд шинэ `app.py`-г ашиглаж болно. Энэ хувилбар `applications` хүснэгтийг хэвээр хадгалсан тул өмнөх бүртгэлүүд үлдэх боломжтой.

## Зураг
Өөрийн зургуудыг `static/images/` болон `static/images/programs/` хавтсанд байршуулна. Одоогийн CSS нь зураг байхгүй үед ч ажиллах байдлаар хийгдсэн.

## Чухал хамгаалалтын санамж
- `SECRET_KEY`-г deployment хийхийн өмнө орчны хувьсагчаар өөрчил.
- Админы нууц үгийг код дотор бичээгүй; `flask --app app create-admin` командаар hash хэлбэрээр хадгална.
- `debug=True` нь зөвхөн локал хөгжүүлэлтэд. Интернетэд байрлуулахын өмнө debug-ийг унтрааж, HTTPS, CSRF хамгаалалт, backup, rate limiting зэрэг нэмэлт хамгаалалт хийнэ.
- Энэ хувилбар нь сургалтын/локал хөгжүүлэлтийн эхлэл бөгөөд шууд production серверт байрлуулахад бэлэн хамгаалалтын бүрэн аудит хийгдээгүй.
